☁️ Sao lưu Google Drive (24/7)

Đang tải...
🔗 Kết nối tài khoản Google
Vào console.cloud.google.com → tạo dự án → bật Google Drive API → tạo OAuth client loại "TVs and Limited Input devices" (mục Credentials). Sau đó dán Client ID / Client Secret vào đây. Google chỉ cho phép LiteNVR quyền drive.file (chỉ thấy các file do chính LiteNVR tạo ra) — đủ để tạo thư mục riêng và sao lưu. Hướng dẫn từng bước có trong README («Sao lưu Google Drive»).
